## 3. Key Changes

### 3.1 设置项 G1 — 保存方式

- 新文件 `app/src/main/java/com/elder/data/export/ElderSaveModeRepository.kt`:
  - `enum SaveMode { LOCAL, CLOUD, BOTH }`,默认 `LOCAL`
  - 独立 prefs 文件 `"elder_save_mode"`(沿用 §A.16.3 `elder_oss_keys` 同款独立文件策略)
  - 字段 `KEY_MODE`(String)+ `KEY_VOICE_END_HINT`(Boolean)
  - 公开 API:`current(): SaveMode` / `setMode(mode)` / `isVoiceEndHintDismissed()` / `markVoiceEndHintDismissed()`
- `ElderSettingsViewModel` 新增 `saveMode: SaveMode` state + `showSaveModeDialog: Boolean` + `setSaveMode()` / `showSaveModeDialog()` / `dismissSaveModeDialog()`
- `ElderSettingsScreen` 新增 `SettingRowSaveMode(current, onClick)` 卡(仿 `SettingRow2FontScale` 风格)+ `SaveModeDialog(current, onPick, onDismiss)` 三选一 AlertDialog
- `strings.xml` 新增 9 条 key(详见 §6 strings)

### 3.2 保存路径 G2 — `SaveExportRepository`

- 新文件 `app/src/main/java/com/elder/data/export/SaveExportRepository.kt`:
  - 单例,`ServiceLocator.saveExportRepo` 注入(`ServiceLocator.init()` 时构造)
  - 依赖:`appContext`, `OssSyncActions`(接口;`OssSyncRepository` 实现)
  - 公开 API:
    ```kotlin
    suspend fun exportIfNeeded(diary: DiaryEntryEntity, audioFile: File, mode: SaveMode): ExportOutcome
    suspend fun writeLocal(diary: DiaryEntryEntity, audioFile: File): String  // 仅本地
    ```
  - 返回 `sealed class ExportOutcome { LocalWritten / CloudSuccess / Both / Failed / CloudThrottled / Skipped }`
- 文件名:`diary_yyyyMMdd_HHmmss_xxxx.{md|m4a}` — 4 位 hex 随机后缀防多设备冲突(同 prefix)
- 时区:`ZoneId.systemDefault()`(设备本地;与 §3.1.7 `LocalDate.today()` 一致)
- 路径:`Environment.getExternalStoragePublicDirectory(DIRECTORY_DOWNLOADS) + "/老友日记/"`
- `.md` schema 5 字段:`# {date}` / `> {summary}` / `{text}` / `时长：{N} 秒` / `录音：{audio_filename}`
- 云模式:复用 v0.10.0 §6.5 `OssSyncRepository.enqueueDebounced() + syncDiary(id)`;OSS 未配置 → `Skipped("oss_config 未配置")` → 静默 fallback LOCAL + 弹 ElderToast「云未配置,已保存到本地」(留给 v0.11.0.x PR 实现)
- 不重试:失败只记 `Log.w` + 返回 `Failed`;ViewModel 不阻塞,可继续触发
- `OssSyncRepository` 抽接口 `OssSyncActions { enqueueDebounced / syncDiary }` 便于测试桩替换(避免反射 OssSync 私有依赖)
- `ServiceLocator.saveExportRepo` 注入 `OssSyncRepository`(实现了 `OssSyncActions`)

### 3.3 LLM 回复 G3 — 顶栏瞬态 Toast

- `InterviewScreen.kt`:
  - **删除** `AssistantCard` composable(约 30 行)及其调用
  - `TranscriptCard` 改 `Modifier.weight(1f)`(撑满剩余空间)
  - 新增 `LLMReplyToast(text: String?)` composable:
    - `AnimatedVisibility` 控制 fadeIn 200ms + fadeOut 500ms
    - 字号 `FontSize.body()`,颜色 `BrandColor.TextSecondary`,背景 `BrandColor.CardWhite`
  - 位置:`TopAppBar` 与正文 `Column` 之间
- `InterviewUiState` 新增字段:
  - `llmReplyToastText: String?` — 当前显示的 LLM 回复文字;`null` = 不显示
  - `farewellText: String?` — 落幕语(走 `finalizeViaExplicitEnd` 时设置;ViewModel 用来 TTS 播报而非 summary)
- `InterviewViewModel.speakOrShow()` 末尾:
  - 增加 `showLlmReplyToast: Boolean = true` 参数
  - 调 `showLlmReplyToast(text)`:`llmRejectedIfAlreadyShown` 早退(幂等),新 text 重置 2.5s dismiss job
  - `llmToastShowMs = 2_500L` 常量
- 老人文字 transcript 占满屏 → `BodyHugeSp=40sp` / `TranscriptLineHeightSp=56sp` 不变

### 3.4 提前结束 G4 — 粤语语音关键词

- `AgentSafety.kt` 新增 end 词集合 + `isElderEnd()`:
  ```kotlin
  /** v0.11.0 §3.4:老人主动结束对话的粤语关键词。 */
  private val elderEnd = setOf("结束", "够了", "拜拜", "不聊了")  // 对应 docs/v0.11.0.md §3.4

  fun isElderEnd(text: String): Boolean = elderEnd.any(text::contains)
  ```
- `SafetyAgent.kt`:
  - 新 `enum Verdict.ELDER_EXPLICIT_END`(与 `EMERGENCY` / `EXPLICIT_CLOSE` / `MONEY` / `MEDICAL` / `SAFE` 并列)
  - `check()` 在 `isElderEnd` 命中时返回 `ELDER_EXPLICIT_END`(优先级高于 `EXPLICIT_CLOSE`)
  - 新常量 `const val ELDER_END_GOODBYE = "好的，今天先聊到这。"`
- `ChatAgent.kt`:
  - `respond()` switch 加分支 `Verdict.ELDER_EXPLICIT_END -> return finalizeViaExplicitEnd(credentials, session, normalized)`
  - 新方法 `finalizeViaExplicitEnd(credentials, session, elderText)`:
    - 复用 `SaveAgent.saveDiary()` 出 text / summary
    - `AgentFinalDraft.farewellText = SafetyAgent.ELDER_END_GOODBYE`
    - 返回 `AgentTurnResult.Finalize(...)`
- `AgentModels.kt` 新增 `AgentFinalDraft.farewellText: String? = null`(默认 null,向后兼容)
- `InterviewViewModel`:
  - `Finalize` 分支:`ttsSpoken = result.value.farewellText ?: result.value.summary`
  - 即:走 `finalizeViaExplicitEnd` 路径时,落幕 TTS 播 `ELDER_END_GOODBYE`;否则播 summary
- 触发条件:`stage in {READY, RECORDING, THINKING, SPEAKING}` 任意命中 end 词
- THINKING/SPEAKING 阶段:不打断当前 LLM/TTS 流;等当前流自然完成后走 final LLM 流 → 落幕 TTS → finalizeViaExplicitEnd
- **黄条教学**:访谈屏 `READY` 阶段顶部黄色提示条(`BrandColor.NetYellow` token + 24sp 文字 + 关闭按钮)
  - 文案:「想提前结束?可以讲"结束"、"够了"、"拜拜"」
  - 首次显示后写入 `elder_save_mode` 同款 prefs file 的 `voice_end_hint_seen=true`
  - 后续不再弹;**用户行为不变**:黄条不阻塞交互,可关闭

### 3.5 路由 / 导航

- `Routes.kt` 不新增(保存方式在 `ElderSettingsScreen` 内部 dialog,无新页面)
- 早退落幕后 `InterviewViewModel.saveDiary(onDone)` 走原路径 → `onDone()` 弹回主屏,不改动

## 7. Assumptions & Defaults

1. **保存方式默认 = 仅本地**(用户在设置里手动切换)
2. **本地路径 = 公共 Downloads/老友日记/**(需要 `WRITE_EXTERNAL_STORAGE` 仅 API 26–28;API 29+ 走 scoped storage)
3. **文件名 = `diary_yyyyMMdd_HHmmss_xxxx.{md|m4a}`**(4 位 hex 后缀,设备本地时区)
4. **气泡交互 = 顶栏瞬态 Toast**(不渲染卡片、不留历史)
5. **早退 UX = 语音关键词 4 词粤语**(教学方式:访谈屏 READY 阶段顶部黄条一次,可关闭后写 prefs)
6. **一份 diary 一份 .md + 音频**(不按 turn 拆)
7. **云模式 + OSS 未配置 → 静默 fallback LOCAL + 弹 ElderToast**(不报错阻塞)
8. **§18 例外**:本次新增 §3.1.4 B 关键词 4 词粤语 end 词(由 §3.4 锁定);不动 A1–A3 / B1–B3 / C / D 既有约束
9. **不动 §5 数据模型字段**;Room schema 不变(`diary_entry_local` 不加列);OSS 同步复用 v0.10.0 §6.5 既有 `OssSyncRepository`
10. **不动服务端代码**(v3.0 MVP 本地 App 范围)
