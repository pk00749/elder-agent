### 1.2 各屏改进点

#### 主屏 (P0 — 老人每次打开必看)

- **现状**:问候语 + 日期 (一行小字,正文 **24sp / 次级色**) + ASR 未配置红卡 (中文 + 副文案) + 顶部两枚按钮 (设置/记录) + "按下开始说"主按钮 (38sp / Brand500)。
- **改进**:
  - 日期行提升到 **28sp 主色**(现在是 24sp 次级色,几乎看不清)
  - 问候语 `早上好` / `中午好` / `晚上好` 改为动态可配(支持 PR #6 已埋的"今日农历日期"注入)
  - ASR 红卡 `语音功能还没准备好` + 副文案 → 简化为单行 28sp `去 AI 服务设置`(次级文案对老人意义不大,主行动按钮做唯一焦点)
  - "记录"按钮内 `▶ 今日记录` 加数字徽章 (今日已记录数),增强反馈
  - 新增 **空态**:`今天还没记录,按下面大按钮开始说` (主屏永远不为空白,见 §4)

#### 录音闭环屏 (P0 — 核心动线)

- **现状**:`写日志` (32sp 标题) + 进度条 (NetworkYellowBar) + 录音区 (信纸风格, 转写 **32sp / Medium**) + 主按钮 (96dp / "点击停止")。
- **改进**:
  - 信纸区当前最大字号 **32sp (XLARGE)**;老人反映"字太小"。提到 **40sp BodyHugeSp**(`Dimens.FontSize.BodyHugeSp = 40`,token 已有)
  - 录音时长从 `MM:SS` 改为 `MM分SS秒`(语义化)+ 字号 38sp
  - 信纸样式保留(老人喜欢纸质感),但行高 `TranscriptLineHeightSp = 48sp` 提到 **56sp**(与 40sp 字号匹配,1.4 倍行高)
  - ASR 黄条高度 `WarningCardMinHeight = 120dp` 保留(已合规 §4.9),但黄条 + 录音区同时出现时竖向挤压;改为 **横滑**:黄条 top,录音区 bottom 时,黄条改为半透明浮层

#### 访谈屏 (P0 — 5–8 轮对话核心)

- **现状**:`第 N 轮 / 共 8 轮` (24sp) + 助手卡片 (XLARGE 32sp) + 转写卡片 (XLARGE 32sp) + 大按钮 (96dp)。
- **改进**:
  - 助手卡片 ack (10 字次级色) + probe (25 字主色) 视觉权重对比不强。改为:ack **次级色 28sp**,probe **主色 38sp 粗体**,中间加分隔点 `·`
  - 转写卡片字号 32sp → **38sp BodyHugeSp**;`FontWeight.Medium` → `Bold`(用户自己说出口的话要看清)
  - 顶部进度行 `第 3 轮 / 共 8 轮` → 改为大圆环进度 (iOS Health 风格),圆环直径 96dp,老人一眼看到还剩几轮
  - "思考中…" / "正在说给您听…" 状态行加 **动态打字光标** `|`(老人知道"还没死")

#### 今日记录 / 时间轴 (P1)

- **现状**:FilterChip (今天 / 近 7 天) + 列表项 (`HH:mm` + 文本 24sp + "改写"按钮) + 弹窗 (160dp 编辑框)。
- **改进**:
  - 列表项主文本 24sp → **28sp LARGE**(老人手指点选某条时需要看清内容)
  - 时间从 `HH:mm` 改为 **相对时间** `今天 上午 9:30` / `昨天 下午 4:00` / `9月15日 上午`(老人对相对时间更敏感)
  - 列表行高度 `ListRowMinHeight = 72dp` → **96dp**(与按钮同档,避免误触)
  - 编辑弹窗字号 24sp → **32sp**,编辑框高度 160dp → **240dp**(老人手写习惯)

#### 设置 (P1)

## 2. 目标 2: 文字显示清晰度 (与 §1 联动)

### 2.1 字号分档重审

当前 token 表(摘自 `Dimens.FontSize`):

| 档位 | 当前 sp | 0.9.0 调整 | 用途 |
|------|--------|-----------|------|
| `BodyHugeSp` | 40 | **保持 40** | 主屏问候语 / 转写 / 录音时长(超大字) |
| `TitleXLargeSp` | 44 | **保持 44** | 当前未用,预留 |
| `TitleLargeSp` | 38 | **38 → 40**(与 BodyHugeSp 合并) | TopAppBar 标题 |
| `TitleDefaultSp` | 32 | **保持 32** | 子页标题 |
| `BodyXLargeSp` | 32 | **保持 32** | 摘要 / 列表主文本(下移到 28) |
| `BodyLargeSp` | 28 | **保持 28** | 主屏日期 / 副标题 |
| `BodyDefaultSp` | 24 | **保持 24** | 正文 / 按钮(下移到 28) |
| `BodyInputSp` | 22 | **保持 22** | 输入框文本 |
| `BodySmallSp` | 18 | **18 → 22**(再小老人看不清) | 副文案 / FilterChip |
| `caption()` | 20 | **20 → 22** | 时间戳 / 红点旁 |

> **核心原则**:老人端**最小可视字号 = 22sp**(原 18 / 20 直接废除或合并)。`BodyDefaultSp = 24` 作为默认正文。

### 2.2 行高 / 字重 / 颜色对比

- **行高**:与字号配 1.4 倍(`lineHeight = fontSize * 1.4`),`TranscriptLineHeightSp = 48sp`(原 48,匹配 32sp → 现在匹配 32sp 不变,但若 32→40 则提到 56sp)
- **字重**:
  - 标题/主操作 → `FontWeight.Bold`
  - 主正文 → `FontWeight.Medium`(替代 `Normal`,老人反映"普通字像没力气")
  - 次级文案 → `FontWeight.Normal`
- **颜色对比**(WCAG AA ≥ 4.5:1):
  - `TextPrimary #1A1A1A` on `CardWhite #FFFFFF` → 16.1:1 ✅
  - `TextSecondary #666666` on `CardWhite #FFFFFF` → 5.7:1 ✅
  - `TextSecondary` on `NetYellow #FFF4E6` → 5.2:1 ✅
  - `Brand500 #4A7A4A` on `CardWhite` → 5.1:1 ✅
  - `Error500 #C44545` on `CardWhite` → 5.8:1 ✅
  - **新增**:`TextTertiary` #999999 仅用于"分隔符 / 占位符"等纯装饰,不承载信息(对比 2.85:1 不达标)

### 2.3 中文长字符串截断 / 折行

- `TextOverflow.Ellipsis` 不用(老人看不懂 `…`)
- `maxLines` 默认 2,超过显示完整(主屏问候语等场景);列表项设 `maxLines = 3 + 展开按钮`
- `softWrap = true` + `LineBreak.Heading`(中文按字断行)替换默认按词断行
- 转写卡片:字号 38sp / 屏幕宽 360dp → **每行 8 字**;考虑老人阅读节奏,设置 `lineHeight = 56sp` + 段间距 `Spacing.Lg`

### 2.4 国际化与多语言

- **现状**:仅 `values/strings.xml`(中文),无 `values-en/strings.xml`。
- **0.9.0**:
  - 新增 `values-en/strings.xml` 英文 fallback,**仅覆盖 v0.9.0 新增 key**(OPENING 阶段 + SafetyAgent 兜底),**不**翻译既有字符串(`home_diary_button` / `home_settings_button` 等)——既有字符串粤语化 / 英文化是独立 PR,避免打破既有 Compose 测试断言(`onNodeWithText("按下开始说")` 等)。
  - 新增 `values-zh-rHK/strings.xml` **粤语口语**(同上,仅 v0.9.0 新增 key)。App UI 文字保留普通话,粤语仅在 **LLM 输出 (assistant_text)** 中体现(§A.13 MiniMax Cantonese_KindWoman TTS)。
  - 文案字符数约束:UI 短文案 ≤ 12 字,长文案 ≤ 30 字;超过则拆分或缩写
  - 现有字符串 i18n(全面翻译 / 粤语口语化)是 v1.0.0 PR,不在 v0.9.0 范围。

## 3. 目标 3: Agent 拆分 (1 → 3)

### 3.1 现状 (1 个 Agent)

```
InterviewAgent (system_v3 + save_v3, 102 + 39 行)
├── respond()           # 主循环(急救 / 金钱 / 闲聊 / 工具调用 / 收尾)
├── summarize()         # PendingDiaryBackfill 用
├── backgroundLearning()# F5:save_diary 后抽 facts
└── finalize()          # 收尾
```

工具 6 个,职责混杂:
- 安全(`ask_clarify`)
- 收尾(`save_diary` / `mark_dimension_covered` / `MOVE_ON`)
- 记忆(`remember_fact` / `search_memory`)

### 3.2 拆分方案 (3 个 Agent)

| Agent | 触发场景 | Prompt 文件 | 工具集 | 拆出理由 |
|-------|---------|------------|--------|---------|
| **ChatAgent** (闲聊) | 主访谈循环(默认) | `assets/agent/chat_v1.txt` (新) | `ask_clarify / mark_dimension_covered / MOVE_ON` (3 个) | 与 `save_diary` / `remember_fact` 解耦,闲聊 prompt 不需要安全收尾指令 |
| **SafetyAgent** (急救 / 金钱 / 医疗) | AgentSafety 命中即调,绕过 LLM 直接调工具 | **无需 LLM**,仅本地判定 | `save_diary / ask_clarify` (2 个) | 急救是硬规则,**不上 LLM**(避免 LLM 误判"胸口疼"为闲聊);金钱 / 医疗由 ChatAgent 命中关键词后委托 SafetyAgent 走固定 reply |
| **MemoryAgent** (记忆 / 总结) | save_diary 落库后追加一次,以及显式 search | `assets/agent/memory_v1.txt` (新) | `remember_fact / search_memory` (2 个) | 记忆抽取是独立子任务(background learning);不污染 ChatAgent 的对话上下文 |

```
ChatAgent
├── respond() → 命中 emergency / money / medical → SafetyAgent.shortcut()
├── finalize() → save_diary → 落库后 → MemoryAgent.backgroundLearning()
└── onDemand search → MemoryAgent.searchFacts()
SafetyAgent
├── shortcut(emotion: EMERGENCY|MONEY|MEDICAL) → 固定 reply (无 LLM)
└── tool: save_diary / ask_clarify (本地执行)
MemoryAgent
├── extractFacts(transcript) → List<Fact>
└── searchFacts(query, limit) → List<Fact> (走本地 Room,非 LLM)
```
