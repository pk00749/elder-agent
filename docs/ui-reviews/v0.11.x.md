### 3.1 已修复(本轮)

#### `ElderSettingsScreen.kt` — 阻塞 bug:设置页不能上下滚动

**根因**:
- 内部 `Column(modifier = Modifier.fillMaxSize())`(原 line 102)无 `verticalScroll` 修饰符
- 当设置项(10 个 SettingRow + 9 个 Divider + Spacer + TopAppBar)累计高度 > 视口高度(尤其小屏 < 5.5"),底部"退出登录"按钮被截掉,老人无法退出登录
- 触发 AGENTS.md §18 "500 行以上文件需文档化理由"+ §3 单文件 ≤ 400 行(本文件 487 行,本 bugfix 加 7 行 → 487 行 < 500,本轮不动)

**修复**(对应 AGENTS.md §3 / §9 / prd.md §3.1.8):
1. 新增 imports:`androidx.compose.foundation.rememberScrollState` + `androidx.compose.foundation.verticalScroll`
2. 内层 Column 修饰符改为 `Modifier.fillMaxSize().verticalScroll(rememberScrollState())`
3. 加注释引用本次 bugfix 的 prd / docs 版本,便于后续 AI agent 不重新打开这个 bug

**新增 import 行号**:`ElderSettingsScreen.kt:24,25`
**Column 改动行号**:`ElderSettingsScreen.kt:102-107`(原 line 102)
**新增 / 删除 / 改动总行数**:+8 / -1 / 0(净 +7 行,文件 480 → 487)
**diff**:
