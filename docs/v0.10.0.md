## 2. 目标 2:TTS 尾音停顿(`MAX_DRAIN_MS` 收紧)

### 2.1 根因

`PcmSink.drainBuffer()` 用 `MAX_DRAIN_MS = 5_000L` 兜底;24kHz mono 25 字 TTS ≈ 3s 音频,实际 headSupplier 追平在 ~1s 内完成;但默认 5s 超时让 `drain()/release()` 多等 ~1-4s 才返回,体感"明明放完了还要等好几秒才停"。

### 2.2 目标实现

- `PcmSink.kt`:`MAX_DRAIN_MS` 5_000L → 1_500L;`POLL_INTERVAL_MS = 10L` 保留
- `AndroidPcmSinkDrainTest.kt`:原有 4 条保留,新增第 5 条锁定数值(`MAX_DRAIN_MS == 1500L`)
- §18 反向条款不变(`drain()/release()` 必须先 `drainBuffer()`)

### 2.3 不动契约

- `drainBuffer(headSupplier, totalSamples, sleep, maxDrainMs, pollIntervalMs)` 入参契约不变
- `release()` 走同一 `drainBuffer()`,自动收紧
- 千问 TTS / MiniMax TTS 客户端代码不动,只调下层 PcmSink

### 6.5 `OssSyncClient` / `Repository`

```kotlin
interface OssSyncClient {
    suspend fun putObject(prefix: String, key: String, file: File, contentType: String): String

}
```

### 7.2 浅色翻深色必须同步的 4 处

1. **次要文字要变深而不是变浅**。暗色里 `#8E8E93` 比正文暗,浅色里 `#8A8A8E` 必须比正文 `#1A1A1C` **浅**——照抄暗色的对比度逻辑会直接看不清。
2. **图标换深色描边版**,`strokeWidth` 保持 **1.8**,不准用半透明灰。
3. **遮罩终点色**从 transparent 前加一站 `#FFFFFF`(浅色卡片底色),否则渐隐会露到灰卡片边缘上;暗色直接用 transparent。
4. **阴影替代提亮**。暗色卡片没有投影靠亮度分层,浅色必须有极淡投影(0.05 透明度封顶,再重就变 Material 老味道)。
