# ChatAgent 0.9.0 拆分详细设计

> 对应 docs/0.9.0-goals.md §3 (Agent 拆分) / AGENTS.md §11 (Prompt 版本化) / §A.11 (本地 Agent) / prd.md §3.1.4 (A1–D3 行为约束)。
> 本文件定义 ChatAgent 的**接口 / 状态 / 工具集 / 调用关系**,代码层细节留给 PR。

## 1. 现状盘点:`InterviewAgent` 内部全景

| 维度 | 当前值 |
|------|--------|
| 文件 | `app/src/main/java/com/elder/agent/InterviewAgent.kt`(624 行,含 companion) |
| 入口 | `respond() / summarize() / backgroundLearning() / finalize() / completeDraft() / completeReply()` |
| 工具 | 6 个(TOOLS 常量) |
| 内部状态 | `coveredDimensions: MutableSet<Dimension>`(session 级) |
| 常量 | 9 个公开 / 4 个固定中文 reply |
| 测试 | `InterviewAgentTest.kt`(6 用例)+ `InterviewAgentTest_v2.kt`(7 用例) |
| 调用方 | `InterviewViewModel.kt:242` 唯一调 `agent.respond()`;`ServiceLocator.kt:109` 唯一构造 |

### 1.1 当前职责(7 类混杂)

```
InterviewAgent.respond() 一次调用内做:
  ① 安全短路 (AgentSafety.isEmergency / isMoneyOrMedical)        ← SafetyAgent
  ② 轮数上限                                                    ← ChatAgent
  ③ LLM 主循环 + 工具调用 (6 工具)                               ← ChatAgent + MemoryAgent
  ④ 单段回复 ≤25 字（v0.9.1 起；取消 v0.6.0 ack/probe 双段拆段）  ← ChatAgent
  ⑤ 维度跟踪 (coveredDimensions)                                 ← ChatAgent
  ⑥ 收尾判定 (dimensionReady / isExplicitClose / maxTurns)        ← ChatAgent
  ⑦ finalize() 调 LLM 走 save_v3 prompt 输出 text/summary         ← SaveAgent (新)
```

`backgroundLearning()` 单独拎出,但仍在 InterviewAgent 内 —— 这部分应该搬给 **MemoryAgent**。
`summarize()` 是 v0.5.0 兼容路径(`PendingDiaryBackfill` 还在用) —— 0.9.0 可保留,但职责归属 **SaveAgent**。

## 2. 0.9.0 ChatAgent 接口

### 2.1 职责边界

| 归属 ChatAgent | 归属 SafetyAgent | 归属 MemoryAgent | 归属 SaveAgent (新) |
|----------------|------------------|------------------|---------------------|
| LLM 主循环 + 工具调用(限定 3 个工具) | emergency / money / medical 关键词命中 → 固定 reply | save_diary 后追加一次抽 facts | PendingDiaryBackfill 仍走的 `summarize()` |
| 单段回复 ≤25 字（**v0.9.1 起**：取消 v0.6.0 ack/probe 双段拆段） | **不上 LLM** | `extractFacts()` + `searchFacts()` | `summarize(transcript) → (text, summary)` |
| 维度跟踪 (coveredDimensions) | `save_diary` / `ask_clarify` 直调 | 走 Room,**不污染** ChatAgent 对话上下文 | 走 `save_v3.txt` prompt |
| 收尾判定(dimensionReady / explicitClose / maxTurns) | 本地 `object` | LLM 调用走独立 `memory_v1.txt` | 单次 LLM 调用 |
| `chat_v1.txt` prompt 加载 | 加载空模板 | 注入 `<elder-facts>` / `<recent-summaries>` | 不含工具 |
| 工具:`ask_clarify / mark_dimension_covered / MOVE_ON` | — | 工具:`remember_fact / search_memory` | — |

### 2.2 类签名(对照现状行号)

```kotlin
// 新文件:app/src/main/java/com/elder/agent/ChatAgent.kt
class ChatAgent(
    private val llmFactory: LlmClientFactory,
    private val prompts: ChatPrompts,                  // 新接口,仅 chat()
    private val safety: SafetyAgent = SafetyAgent,     // 默认 object
    private val memory: MemoryAgent? = null,           // null 时 finalize 后跳过 backgroundLearning
    private val maxTurns: Int = MAX_TURNS,             // 8
    private val retryCount: Int = MAX_RETRIES,         // 3
) {
    private val coveredDimensions = mutableSetOf<Dimension>()

    suspend fun respond(
        credentials: LlmCredentials,
        session: InterviewSession,
        elderText: String,
        recentSummaries: List<DiarySummary> = emptyList(),
        elderFacts: List<ElderFact> = emptyList(),
        onDelta: suspend (String) -> Unit = {},
    ): AgentTurnResult

    /** v0.5.0 兼容路径保留,但内部委托给 SaveAgent(0.9.0 唯一 call site 是 PendingDiaryBackfill) */
    suspend fun summarize(credentials: LlmCredentials, transcript: String): Pair<String, String>

    /** v0.6.0 F5:save_diary 落库后追加 → 委托给 MemoryAgent */
    suspend fun backgroundLearning(credentials: LlmCredentials, transcript: String): Int

    companion object {
        const val MAX_TURNS = 8
        const val MAX_REPLY_CHARS = 25  // A2 单段回复 ≤25 字（v0.9.1 起统一为单段，不再拆 ack/probe）

        // 仅 ChatAgent 暴露给 LLM 的工具
        const val TOOL_ASK_CLARIFY = "ask_clarify"
        const val TOOL_MARK_DIMENSION = "mark_dimension_covered"
        const val TOOL_MOVE_ON = "MOVE_ON"

        private val TOOLS = listOf(ASK_CLARIFY, MARK_DIMENSION, MOVE_ON)
        private val TOOL_NAMES = TOOLS.map { it.name }.toSet()

        private const val MAX_TOOL_ROUNDS = 3
        private const val MAX_RETRIES = 3
        private val RETRY_DELAYS_MS = longArrayOf(500L, 1_000L)
        private const val FALLBACK_REPLY = "嗯，然后呢？"
        private const val CLARIFY_RESULT = "已换到轻松日常话题，请继续问一个短问题。"
    }
}
```

**关键变化**:
- 类名 `InterviewAgent` → `ChatAgent`(避免歧义)
- 字段 `prompts: PromptProvider` → `prompts: ChatPrompts`(只读 `chat()` 方法,**不再有 save()**)
- 字段 `elderFactRepo: ElderFactRepository?` 删除(改由 `MemoryAgent` 持有)
- 工具集从 6 个 → **3 个**(`ask_clarify / mark_dimension_covered / MOVE_ON`)
- `summarize()` / `backgroundLearning()` 改为 **委托给 SaveAgent / MemoryAgent**;ChatAgent 自身不实现

### 2.4 安全短路迁移(`respond()` 入口)

```kotlin
// 现状(InterviewAgent.kt:58-65)
if (AgentSafety.isEmergency(normalized)) {
    return finalize(credentials, session, normalized)
}
if (AgentSafety.isMoneyOrMedical(normalized)) {
    return completeReply(session, normalized, assistantText = MONEY_MEDICAL_REPLY, shouldFinalize = false)
}

// 0.9.0(ChatAgent.respond 入口)
val safetyVerdict = safety.check(normalized)     // SafetyAgent.check() 返回 enum
when (safetyVerdict) {
    SafetyVerdict.EMERGENCY -> return saveFinalize(credentials, session, normalized)  // 走 save_diary
    SafetyVerdict.MONEY, SafetyVerdict.MEDICAL -> return completeReply(
        session, normalized, assistantText = SafetyAgent.SHORT_REPLY, shouldFinalize = false,
    )
    SafetyVerdict.SAFE -> { /* 走主 LLM 循环 */ }
}
```

`SafetyAgent` 替代硬编码的 `AgentSafety.isEmergency / isMoneyOrMedical`,作为 ChatAgent 的依赖注入。**SafetyAgent 不持 LLM**(纯本地 object),对应 §A.11.4"急救关键词本地拦截"。

### 2.5 主循环迁移(`toolCalls` 处理)

```kotlin
// 现状(InterviewAgent.kt:79-122,6 个 when 分支)
when (call.name) {
    TOOL_SAVE_DIARY -> { return completeDraft(...) }     // → SaveAgent.saveDiary()
    TOOL_ASK_CLARIFY -> { /* 同 */ }                       // → ChatAgent 自留
    TOOL_MARK_DIMENSION -> { /* 同 */ }                    // → ChatAgent 自留
    TOOL_MOVE_ON -> { /* 同 */ }                           // → ChatAgent 自留
    TOOL_REMEMBER_FACT -> { /* 同 */ }                     // → 删除
    TOOL_SEARCH_MEMORY -> { /* 同 */ }                     // → 删除
}

// 0.9.0(ChatAgent.respond 工具循环)
while (lastResult.toolCalls.isNotEmpty() && toolRound < MAX_TOOL_ROUNDS) {
    val call = lastResult.toolCalls.first()
    validateCall(call)
    when (call.name) {
        TOOL_ASK_CLARIFY -> { /* 同 v0.6.0,自己处理 */ }
        TOOL_MARK_DIMENSION -> { /* 同 v0.6.0 */ }
        TOOL_MOVE_ON -> { /* 同 v0.6.0 */ }
        else -> throw AppError.LlmUpstream("unsupported tool ${call.name}")
    }
    toolRound += 1
}
```

`completeDraft()` 改为 ChatAgent 内部仍调用,但**实际调 LLM 生成 text/summary 的部分**委托给 `SaveAgent.saveDiary()`:

```kotlin
TOOL_SAVE_DIARY 在 ChatAgent 中不再暴露给 LLM;ChatAgent 收到 save_diary 工具调用时:
1. 解析参数 (text, summary)
2. 委托 SaveAgent.saveDiary(credentials, session, transcript) 走 save_v3.txt
3. 返回 AgentTurnResult.Finalize
```

或者更激进:**ChatAgent 完全不识别 save_diary 工具,改由 ServiceLocator 编排** —— 当 ChatAgent 返回 `shouldFinalize = true` 时,ViewModel 主动调 `SaveAgent.saveDiary(...)`。这样 ChatAgent 的工具集彻底只剩 3 个。

> **建议方案**:激进版。ViewModel 收到 `AgentTurnResult.Reply(shouldFinalize = true)` 时,调 `saveAgent.saveDiary(...)`;ChatAgent 不再关心 save_diary 工具 schema。

### 5.1 调用流(完整 8 轮典型)

```
轮 1: 老人:「今天和老伴去公园了」
       ChatAgent: isEmergency=no, isMoneyMed=no
       → LLM(chat_v1) → "这事挺高兴的(ack) → 当时天气怎样?(probe)"
       → mark_dimension_covered(event)

轮 2: 老人:「挺好的,有点晒」
       ChatAgent → LLM → "晒得舒服(ack) → 你们在公园做什么?(probe)"
       → mark_dimension_covered(place)

轮 3: 老人:「有人跳舞,老伴看了半天」
       ChatAgent → LLM → "看起来老伴喜欢(ack) → 老伴平时爱跳舞吗?(probe)"
       → mark_dimension_covered(person)

轮 4: 老人:「她最爱跳广场舞了,年轻时就好玩」
       ChatAgent → LLM → "这事听起来很美好(ack) → 跳得怎么样?(probe)"
       → mark_dimension_covered(feeling)
       coveredDimensions = {event, place, person, feeling} = 4 项
       → dimensionReady = true → shouldFinalize = true

轮 5: ViewModel 收到 Reply(shouldFinalize=true)
       → 调 SaveAgent.saveDiary(llmCredentials, session, turns)
       → SaveAgent 走 save_v3.txt → 输出 {text: "今天和老伴...", summary: "和老伴去公园看跳舞"}
       → 落 diary_entry_local
       → 调 MemoryAgent.backgroundLearning(transcript)
       → MemoryAgent 走 memory_v1.txt → 输出 {facts_to_remember: [...]}
       → 调 elderFactRepo.rememberFact × N
       → ViewModel 切换 InterviewStage.REVIEW,展示 summary/text 给老人
```

### 5.2 应急路径对比

**现状**(`InterviewAgent.kt:58-60`):
```kotlin
if (AgentSafety.isEmergency(normalized)) {
    return finalize(credentials, session, normalized)   // ← 直接走 finalize,LLM 跑一遍 save
}
```

**0.9.0**:
```kotlin
// ChatAgent.respond() 入口
val verdict = safety.check(normalized)
if (verdict == SafetyVerdict.EMERGENCY) {
    // 不调 ChatAgent 主 LLM;直接 SaveAgent.saveDiary + MemoryAgent.backgroundLearning
    return saveAndRemember(credentials, session, transcript, safety.emergencyNote())
}
```

`SafetyAgent` 持有 `emergencyNote()` 返回固定中文(从 `EMERGENCY_REPLY` 改造成一句话存入 diary summary)。这样 emergency 路径**省一次 LLM 调用**(原 v0.6.0 也要 finalize 调 LLM)。
