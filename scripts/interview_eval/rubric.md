# v0.6.0 对照评分 rubric

> 对应 prd.md §3.1.4 v0.6.0 验收。每次跑 `runner.py` 后，对照 `report.md` 的 v1/v2 对话日志，按以下 5 项打 1–5 分。

## 评分维度（每项 1-5 分）

### 1. 共情到位度（A6 / E1）
- **5 分**：每轮都有 ≤10 字情绪命名 + ≤25 字追问；命名准确反映老人当下的情绪
- **3 分**：部分轮有共情；偶尔遗漏
- **1 分**：纯追问，无情绪命名（v0.5.0 行为）

### 2. 追问递进度（E2 / E4）
- **5 分**：明显按 who → what → how-felt → small-detail 阶梯推进；不重复同维度
- **3 分**：部分轮递进；偶尔跳维度或重复
- **1 分**：连续追问同一维度 / 闭式问句（"是不是""几岁"）

### 3. 跨会话回扣（F 节 / E6）
- **5 分**：Agent 主动用"你常…""上次…"等自然表达回扣 `<elder-facts>` / `<recent-summaries>`，且不复读原文
- **3 分**：有回扣但偏生硬（如"你昨天说…"）
- **1 分**：完全忽略 history / 复读原文（违反 A4 / F6）

### 4. facts 抽取准确率（F5 / F3）
- **5 分**：背景抽取或主动 remember_fact 调用的 facts 与 fixture 期望列表精确率 ≥80%；不抽临时事件；不写 PII
- **3 分**：抽取 ≥60% 期望；偶有临时事件
- **1 分**：抽取与期望完全不一致 / 包含 PII

### 5. 漏关键细节（综合质量）
- **5 分**：与人工对照脚本相比，0-1 处关键细节遗漏
- **3 分**：2-3 处遗漏
- **1 分**：≥4 处遗漏（重大质量事故）

## 评分流程

1. 跑 `python scripts/interview_eval/runner.py`（需 `MINIMAX_API_KEY`）
2. 打开 `report.md`，对照每个 fixture 的 v1 / v2 对话
3. 每个 fixture 按 5 项打 5 个分数
4. 算总分（25 分制），输出 markdown 表格：

```
| fixture | 共情 | 递进 | 回扣 | 抽取 | 漏细节 | v1总分 | v2总分 | 改进 |
|---------|------|------|------|------|--------|-------|-------|------|
| basic.json | 1/3/5 | 1/3/5 | 1/3/5 | 1/3/5 | 1/3/5 | 5/15/25 | 5/15/25 | +X |
| cross_session.json | ... |
```

5. v2 总分显著高于 v1（一般 +5 分以上）即可宣称"窦文涛式访谈技巧 + Hermes 记忆落地"。
